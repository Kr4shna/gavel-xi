# Gavel XI — offline cricket auction simulator

This repository holds the **built, static** Gavel XI app, served by GitHub Pages at
**https://kr4shna.github.io/gavel-xi/**. Open it in Safari on an iPhone and choose
*Share → Add to Home Screen*; after the first load it works fully offline.

Gavel XI is an independent fan-made simulator. It is **not affiliated with, endorsed by, or
connected to the IPL, BCCI or any franchise.** Team and player names are used only to identify
real-world data.
